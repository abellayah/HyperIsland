# HyperIsland - Xiaomi HyperOS Dynamic Notification

Aplikasi Dynamic Island / Dynamic Notification bertema **Xiaomi HyperOS** yang dirancang ringan (*low-RAM footprint*), kompatibel dengan **Android 14 Go Edition (32-bit & 64-bit)**, serta dioptimalkan khusus untuk kamera punch-hole tengah pada **Infinix Smart 9 / Smart 9 HD**.

---

### Fitur Utama
1. **Charging Animation (Mi Turbo Charge)**
   - Kapsul meluas otomatis saat kabel pengisi daya dicolokkan.
   - Ikon petir hijau khas HyperOS dan persentase baterai real-time.
2. **Notifikasi Aplikasi Dinamis (WhatsApp, Telegram, dll)**
   - Menampilkan pengirim dan cuplikan pesan di kapsul hitam melengkung.
   - Ketuk kapsul untuk langsung membuka aplikasi.
   - Usap ke atas untuk menutup kapsul seketika.
3. **Music Player & Equalizer**
   - Mendeteksi pemutaran lagu (Spotify, YouTube Music, dll).
   - Menampilkan judul lagu, artis, serta equalizer gelombang audio 3-bar bergerak.
4. **Peralihan Mode Suara (Ringer Mode)**
   - Menampilkan transisi status Dering (*Regular*), Getar (*Vibrate*), dan Hening (*Silent*).
5. **Kalibrasi Khusus Punch-Hole Infinix Smart 9**
   - Tombol *Reset Preset* langsung mengunci posisi kapsul pada koordinat punch-hole tengah Infinix Smart 9 (Y = 22 dp).
   - Penggeser (Slider) untuk penyesuaian posisi vertikal secara real-time.

---

### Cara Mengunduh & Memasang APK
1. Buka menu **Releases** di repositori ini.
2. Unduh file `HyperIsland-HyperOS-InfinixSmart9.apk`.
3. Buka file APK di HP Infinix Smart 9 kamu dan klik Pasang / Install.
4. Buka aplikasi **Hyper Island**, lalu aktifkan izin yang diminta:
   - **Tampil di atas aplikasi lain (Overlay)**
   - **Akses Notifikasi**
   - **Bebaskan dari Pengoptimalan Baterai**
5. Tekan tombol uji coba (Tes Cas, Tes WA, Tes Musik) untuk mencoba animasi kapsul.
