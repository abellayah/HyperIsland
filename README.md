# HyperIsland - Xiaomi HyperOS Dynamic Notification (DNotch Edition)

Aplikasi Dynamic Island / Dynamic Notch bergaya **Xiaomi HyperOS & DNotch UI** yang dirancang ringan (*low-RAM footprint*), kompatibel dengan **Android 14 Go Edition (32-bit & 64-bit)**, serta dioptimalkan khusus untuk kamera punch-hole tengah pada **Infinix Smart 9 / Smart 9 HD**.

---

### Fitur Utama Baru (Berdasarkan DNotch)

1. **Hanya Muncul Saat Ada Notifikasi (Trigger Only Mode)**
   - Kapsul dynamic tersembunyi total saat diam (*idle*). Layar HP kamu tetap bersih dan tidak ada bar yang menghalangi.
   - Kapsul baru membal keluar (*pop-out spring*) saat ada pemicu: notifikasi pesan (WhatsApp/Telegram), charger dicolok, musik diputar, atau perubahan mode suara hening.
   - Setelah beberapa detik, kapsul mengecil kembali dan menghilang secara otomatis.

2. **Fitur Sembunyikan Status Bar (Hide Bar)**
   - Opsi untuk menutupi/menyembunyikan status bar bawaan (Jam, logo Sinyal, Wifi, dan Ikon sistem).
   - Menghasilkan tampilan layar penuh yang futuristik dan bersih total, sehingga hanya notifikasi dynamic yang tampil.

3. **Dukungan Accessibility Service API Real-time**
   - Menggunakan Accessibility API untuk menangkap notifikasi dan perubahan jendela secara instan dengan latensi sangat rendah.
   - Layanan memiliki prioritas sistem tertinggi sehingga tidak akan dimatikan paksa oleh manajemen RAM agresif XOS Infinix.

4. **Kalibrasi Presisi Infinix Smart 9**
   - Tombol step minus (-) dan plus (+) untuk penyetelan posisi vertikal (Y) dan horizontal (X) per 1 dp.
   - Tombol satu klik: *Preset Infinix Smart 9* (posisi tengah Y = 22 dp).

5. **Modul Lengkap**
   - Notifikasi Pesan (WhatsApp, Telegram, SMS)
   - Animasi Cas Baterai (Mi Turbo Charge dengan persentase real-time)
   - Musik & Equalizer Gelombang Audio
   - Peralihan Mode Suara (Silent / Regular / Vibrate)

---

### Cara Mengunduh & Memasang APK
1. Buka menu **Releases** di repositori ini.
2. Unduh file `HyperIsland-HyperOS-InfinixSmart9.apk`.
3. Pasang APK di HP Infinix Smart 9 kamu.
4. Buka aplikasi, aktifkan **Aksesibilitas**, **Akses Notifikasi**, dan **Tampil Di Atas Aplikasi**.
